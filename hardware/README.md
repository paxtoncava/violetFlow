# Hardware

The syringe pumps are built from the [Poseidon](https://patcherlab.github.io/poseidon/about) design (Patcher Lab, Caltech).

Changes from the original Poseidon parts list were made where originals were unavailable:
1. NEMA 17 stepper substituted with MAKERELE NEMA 17
2. uxcell 5mm to 5mm aluminum coupling used
3. uxcell 6mm x 200mm rods used
4. 6mm linear bearings substituted with MELIFE LM6UU linear bearings
5. M5 x 0.8 threaded rod, 170mm substituted with Arwnnklo 304 stainless M5 x 255mm rod, cut to 170mm
6. M5 x 0.8 nuts included in threaded rod pack
7. M3 x 20mm screws included in Fgruh 720-piece stainless M3 kit
8. M3 x 10mm screws included in Fgruh 720-piece stainless M3 kit
9. M3 nuts included in Fgruh 720-piece stainless M3 kit
10. Kipp M5 star knob (25mm, 50mm screw) substituted with uxcell knurled thumb screw (M5 x 50mm, 25mm head)
11. 12V power supply with plug cut off and wires stripped substituted with Kastar 12 V 6 A supply with a barrel-to-screw-terminal adapter
12. Arduino + CNC shield pack substituted with Elegoo Uno R3 + ACEIRMC CNC Shield V3 with 4 A4988 drivers
13. Raspberry Pi, touchscreen, microscope not needed
14. Syringes not included in original list, LZHNB 20 mL Luer-lock syringes
15. Parts printed in PETG instead of PLA for increased heat resistance
